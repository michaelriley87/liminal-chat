# Liminal Chat

Liminal Chat is a small, temporary chatroom application. Create a room, share its five-character
code, and talk in real time without creating an account.

## Features

- Temporary private rooms
- Simple room codes for inviting others
- Real-time messages
- Join and leave notifications
- Live participant lists
- Responsive desktop and mobile design
- Clear validation and helpful error messages

Rooms disappear after one hour without a message. Conversations are not saved, and restarting
the application removes all active rooms.

## About the project

This graduate portfolio project demonstrates full-stack development with Java, Spring Boot,
WebSockets, Vue, validation, and automated testing.
